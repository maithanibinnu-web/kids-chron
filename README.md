# KidsChron

A premium educational newspaper for curious kids — space, wildlife, science, history and more, told in a way children love.

## Live site

Deployed with **GitHub Pages**: https://maithanibinnu-web.github.io/kids-chron/

## Project structure

```
index.html    # Main page
styles.css    # All styles (extracted from the original inline <style>)
```

## Local preview

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Pushing to the `main` branch automatically publishes the site via GitHub Pages
(Settings → Pages → Source: `main` / root).
